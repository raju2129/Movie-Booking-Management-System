How it works
  • Search and select any movie from your database to add it to the carousel.
  • Upload a custom poster image (JPG/PNG/WebP, max 5 MB) or paste an image URL.
  • Paste a YouTube Trailer URL — a "Watch Trailer" button will appear on the homepage. Supports youtube.com and youtu.be links.
  • Set the Display Order (lower number = appears first).
  • Set the Badge Label (e.g. "NOW SHOWING", "BLOCKBUSTER", "AWARD WINNER").
  • Toggle slides on/off without deleting them. Max 10 slides shown at once.
  • If no slides are active, the site automatically shows 10 random movies.
